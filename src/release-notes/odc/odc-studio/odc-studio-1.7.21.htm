ODC Studio 1.7.21

This is a preliminary version of the document.

New in ODC Studio 1.7.21

  • Buttons and toolbar items now ignore repeated clicks made in quick succession, so a burst of clicks triggers its action only once. (RDEV-10059)

Bug Fixing

  • Fixed an issue that cut off long element names while renaming them in the right pane, by stretching the edit box to the available space. (RDEV-10191)
  • Fixed an error that caused Mentor to stop responding when the changes Mentor applied to an app or library exceeded the memory limit allowed for the operation. (RDPIM-4370)
