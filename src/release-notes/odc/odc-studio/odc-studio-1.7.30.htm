ODC Studio 1.7.30

This is a preliminary version of the document.

New in ODC Studio 1.7.30

  • It is now possible to access and resume previous Mentor conversations. (RDEV-10154)
  • It is now possible to search past Mentor chats by title in the chats panel. (RDEV-10157)

Bug Fixing

  • Improved the edit data experience: the context menus now show disabled items correctly and group options with separators, the confirmation message shown when you apply edited data is now centered, and secondary buttons now use the correct background color in the light theme. (RDEV-10141)
  • Fixed an issue causing crashes when using AI commit messages on large applications. (RDEV-10378)
  • Fixed an unexpected error when canceling Compare and Merge. (RDPIM-4439)
