OutSystems Developer Cloud 2026-09-18

Released on Sep 18, 2026

New

  • Fixed an issue that caused an error when exposing O11 entities to ODC from a non-default database catalog. This occurred when using LifeTime to expose O11 entities that were published in a database catalog different from the main one configured in the registered environment. Now, the O11 Data Fabric connector correctly identifies where the O11 entities are stored, allowing the expose operation to complete successfully. (RDDFT-1764)
  • Added support for consuming Oracle stored procedures, including those defined inside packages, that return primitive-type output parameters, when connecting to an external Oracle database. (RDDFT-326)
