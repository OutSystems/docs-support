ODC Studio 1.7.17

Released on Jul 27, 2026

New in ODC Studio 1.7.17

  • Service Studio has been redesigned with a modernized, distraction-free workspace — featuring a modular panel layout, refreshed typography, and a new iconography system optimised for HiDPI and Retina displays. (RDEV-9752)
  • Now the OnAuthentication callback flow of a new REST API ends in an Exception by default, instead of a plain End, so an app or library fails if authentication logic isn't implemented. (RDEV-9920)

Bug Fixing

  • Fixed an error that would occur when ODC Studio retrieved the display names of users. (RDEV-9971)
  • Fixed an issue where the Forge link stopped working after switching to a different organization. (RDEV-9975)
  • Fixed an error that could occur while signing in, renewing your session, or closing an app or library. (RDEV-9983)
  • Fixed a memory leak that occurred when closing the asset tab. (RDEV-9999)
