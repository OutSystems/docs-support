Cross-platform Service Studio 11.55.78

Released on Jul 07, 2026

Bug Fixing

  • Fixed an issue on Windows where pasting from the clipboard history (Win+V) into the expression editor, the advanced SQL editor or description fields, always inserted the most recent entry instead of the one selected from the history. (RDEV-9865)
  • Fixed an issue where sometimes the styles tab for a given widget would be empty. (RDEV-9871)
  • Fixed an issue where debugger breakpoints would not be hit in some scenarios. (RDEV-9872)
  • Fixed an issue where a color picker was incorrectly displayed in SQL statement editors and expression editors. (RDEV-9907)
  • Fixed an issue causing the enabled state of nodes to be lost during merges. (RPM-6911) Service Studio Merge operation
