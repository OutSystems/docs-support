Cross-platform Service Studio 11.55.91

Released on Oct 02, 2026

Bug Fixing

  • Updated the Convert To Reactive Command to make initial reference gathering faster and more error resilient. (R11DT-4284)
  • Fixed view-related memory leaks to improve overall application stability and reduce memory footprint. (RDEV-10232)
  • Fixed an issue that sometimes caused latency when opening an expression editor. (RDEV-10257)
  • Fixed an issue that opened the ODC Portal instead of the OutSystems 11 Portal when developers clicked “Fetch environment” in the “Environment deleted” pop-up, which stopped them from requesting a new personal environment. This also affected the other personal environment links on the Service Studio login pop-up. (RDEV-10284)
