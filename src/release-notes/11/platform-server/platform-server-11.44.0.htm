Platform Server 11.44.0

Released on Sep 21, 2026

New in Platform Server 11.44.0

  • Removed support for SQL Server 2016 and compatibility level 130. This applies to the platform database, as well as external databases. (R11BCT-508)
  • Updated System.Security.Cryptography.Xml library bundled with the platform from version 10.0.8 to version 10.0.10. (R11BCT-559)
  • Updated the device catalog of the PreviewInDevices system component. (R11DT-4022)
  • Upgraded Swagger-UI dependencies, addressing Security Vulnerabilites. (R11DT-4120)

Bug Fixing

  • You can now use the Documentation = No setting in your Exposed REST APIs to also hide https://hostname/ModuleName/rest/RESTAPI/swagger.json and the REST API documentation page. (RPM-1378) Application Runtime Logic Execution
  • Fixed an issue in Service Center that caused a disabled server to be re-enabled after saving its configuration. This occurred even when no changes were made to the server settings. The 'Save' button now only saves the server configuration without changing its enabled/disabled status, and is only enabled when there are unsaved changes. (RPM-2861) Application Lifecycle Service Center
  • Fixed an issue that caused an error when exposing Entities to ODC from a database catalog other than the default one, with every subsequent attempt to expose the same Entities failing as well. This occurred in self-managed environments configured with Multiple Database Catalogs on SQL Server, and affected exposing, refreshing, and removing exposed Entities. Oracle installations were not affected. Now, the database view that supports the exposed Entity is created, refreshed, and removed in the catalog where the Entity data is stored, and the operation completes successfully. (RPM-6528) O11 ODC Conversion and Coexistence
  • Fixed an issue that caused Weekly Active Users (WAU) and monthly telemetry metrics to be missing from the Customer Portal and Compass. This occurred when telemetry processing exceeded timeout thresholds due to accumulated visitor tracking records in the platform's database. The underlying data cleanup mechanism has been fixed to prevent future occurrences. (RPM-6814) Application Lifecycle Service Center
  • Fixed an issue that caused the preview of submitted App Feedback to render without its original styling. This occurred when viewing feedback captured through App Feedback, because same-origin and relative resources were being removed together with the external ones. Now, the preview preserves same-origin, relative, and allowed-host resources, while resources from external domains remain blocked. You can add allowed hosts with new ECT_Provider Site Property AllowedHosts. (RPM-6916) Application Lifecycle App Feedback Backoffice / ECT
  • Fixes crash on Configuration Tool GUI when SQL Server database is configured with Windows authentication and the logged user is not the one configured as the Admin service account (RPM-7093) Infrastructure Management Platform Configuration
  • Fixed an issue where browser Content Security Policy (CSP) violation reports were logged as errors when they arrived as a single report instead of a list. (RPM-7112) Application Runtime System Components
  • Fixed a vulnerability that could lead to remote code execution via tampered OMLs. (RPM-6968) Publish Operation Compilation
  • Hardened C# code generation by validating and sanitizing custom email header names in module metadata during compilation, addressing a potential Remote Code Execution (RCE) vulnerability (RPM-6970) Publish Operation Compilation
  • Improved the security of the REST API compiler by implementing strict sanitization on incoming OML metadata, resolving a potential Remote Code Execution (RCE) vulnerability during application compilation. (RPM-6974) Publish Operation Compilation
  • Hardened LDAP filter construction to ensure usernames are properly escaped before being used during end-users login flow with LDAP standard. Service Studio now warns when LDAP_Search, LDAP_Search_WithAuthenticationType, or LDAP_Login from the Authentication extension are used with a filter that may contain unescaped, unsafe user input, helping prevent LDAP injection. The warning clears once the filter is built safely with LdapFilterEncode. (RPM-6982) Application Runtime System Components
  • Fixed a security vulnerability in OSP Tool and O11 Integration Studio that could lead to arbitrary files being written to the file system of the machine executing OSP Tool or O11 Integration Studio. (RPM-6996) Integration Studio
  • Fixed a vulnerability that could lead to remote code execution via tampered OMLs. (RPM-7024) Publish Operation Compilation
  • Fixed a security vulnerability that could lead to remote code execution of Frontend Platform servers. (RPM-7025) Publish Operation Compilation
  • Fixed a security issue in the Log Service (LogServer) component that could allow arbitrary code execution through unsafe deserialization of internal log messages. (RPM-7033) Application Runtime Logging
  • Fixed a security vulnerability that could allow external entity resolution in XML files. (RPM-7034) Application Runtime System Components
  • Enhanced the security of Reactive Web error pages by safely processing error messages to prevent potential Cross-Site Scripting (XSS) vulnerabilities. (RPM-7053) Application Runtime
  • Fixed a vulnerability that could lead to remote code execution on Personal environments via tampered OMLs or extensions. (RPM-7068) Infrastructure Management SandBox Manager
  • HtmlSanitizer has been upgraded from version 9.0.892 to the latest patched version 9.1.982. This upgrade brings in a patched AngleSharp, which resolves CVE-2026-54570. The patched libraries ship as part of the Sanitization System Component. (RPM-7097) Application Runtime
