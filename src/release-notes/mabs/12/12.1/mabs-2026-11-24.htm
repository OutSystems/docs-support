MABS 2026-11-24

Released on Nov 24, 2026

New

  • Android release builds can now use R8 code optimizations through dedicated extensibility configurations. (RDMR-1649)

Bug Fixing

  • Fixed an issue on Android where an app closed at certain moments may damage its saved update and run an outdated version until a newer version is published. (RDMR-1633)
  • Fixed an issue where an app closed at certain moments may wrongly consider its update damaged and run an outdated version until a newer version is published. (RDMR-1635)
  • Fixed an issue that caused Cordova apps on Android to show an empty area the size of the keyboard for the whole session when opened from a launcher's search with the keyboard visible. (RDMR-1788)
