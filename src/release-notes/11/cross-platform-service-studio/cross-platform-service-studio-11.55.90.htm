Cross-platform Service Studio 11.55.90

This is a preliminary version of the document.

New in Cross-platform Service Studio 11.55.90

  • Added support for migrating Session Variables in the Traditional to Reactive conversion, converting non-sensitive variables to client variables while sensitive ones are kept on the database. (R11DT-4184)

Bug Fixing

  • Fixed an issue that caused a memory leak when switching between screens and blocks. (RDEV-10097)
  • Fixed an issue where exporting a flow to an image in the light theme produced an image with a black background, making it unreadable. (RDPIM-4362)
