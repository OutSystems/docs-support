OutSystems Developer Cloud 2026-11-09

Released on Nov 09, 2026

New

  • Mentor in ODC Studio now lays out screens with Modern Layouts, using Flexbox and Grid on Containers and Placeholders, so you can keep editing the layout in the Layout section. (RDCAG-172)
  • You can now use Flex and Grid layouts in Containers, Placeholders, and Forms, and control how each child element grows, shrinks, or spans, directly from the Styles Editor. (RDEV-10784)
  • End-user group names now support special characters, such as colons and underscores, and can be up to 128 characters long. Previously, end-user group names were limited to 50 characters and could only contain letters and digits. (RDPP-3537)

Bug Fixing

  • Fixed an issue that caused Mentor to publish an app when you accepted a plan, without asking you to confirm the publish. (RDCAG-171)
  • OutSystems MCP: Fixed an issue that caused tools such as app_logs, app_traces and context_search to fail with a “matches N apps” error when you referred to an app by its exact name and other app names contained it. (RDPIM-4493)
