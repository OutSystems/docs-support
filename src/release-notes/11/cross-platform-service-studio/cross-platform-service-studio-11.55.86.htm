Cross-platform Service Studio 11.55.86

Released on Aug 31, 2026

New in Cross-platform Service Studio 11.55.86

  • Service Studio now warns when LDAP_Search, LDAP_Search_WithAuthenticationType, or LDAP_Login from the Authentication extension are used with a filter that may contain unescaped, unsafe user input, helping prevent LDAP injection. The warning clears once the filter is built safely with LdapFilterEncode. (R11BRT-2509)
  • Added support for migration of RichWidgets layouts Layout_London, Layout_Chicago and Layout_Email, and widgets Input_SetFocus, ResponsiveTableRecords and ApplicationSwitcher to the Convert to Reactive command. (R11DT-4139)

Bug Fixing

  • Fixed an issue that caused a memory leak when switching between screens and blocks. (RDEV-10097)
  • Fixed an issue that caused the debugger to fail on devices running iOS 26 and later. (RPM-6705) Service Studio Debugger
  • Hardened LDAP filter construction to ensure usernames are properly escaped before being used during end-users login flow with LDAP standard. Service Studio now warns when LDAP_Search, LDAP_Search_WithAuthenticationType, or LDAP_Login from the Authentication extension are used with a filter that may contain unescaped, unsafe user input, helping prevent LDAP injection. The warning clears once the filter is built safely with LdapFilterEncode. (RPM-6982) Application Runtime System Components
