ODC Studio 1.7.20

Released on Aug 17, 2026

New in ODC Studio 1.7.20

  • Buttons and toolbar items now ignore repeated clicks made in quick succession, so a burst of clicks triggers its action only once. (RDEV-10059)
  • Improved the user experience of the styles editor to a unified style. (RDEV-10116)

Bug Fixing

  • Fixed an issue that caused an error while syncing app references when starting a Try Library session right after logging in to ODC Studio. (RDEV-10048)
  • Fixed an issue where screen template storage could not be reconstructed when a malformed template was detected. (RDEV-10068)
  • Fixed an issue that caused an internal identifier to be inserted instead of the parameter name when dragging a parameter into the SQL statement of an Advanced Query. (RDPIM-4356)
  • Fixed an issue in UI Editor that caused the preview of some blocks to display 'Expression' instead of the configured property values, such as the column headers of a data grid. (RDPIM-4363)
