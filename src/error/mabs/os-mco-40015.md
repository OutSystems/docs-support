# OS-MCO-40015

## Error message

`The app doesn't have an icon. Define an icon for the app in ODC Studio.`

## Cause

Your mobile app doesn't have an icon defined. The icon is mandatory to build a mobile app, because it becomes the icon of the app installed on the device.

ODC Studio sets a default icon for every app you create with it. Apps created with other tools might not have one.

## Impact

The mobile compilation fails, causing the native mobile build to fail.

## Recommended action

Open the app in ODC Studio and set an icon in the [app properties](https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/libraries/edit_app_library_and_mobile_library_properties/#general-settings-general-settings). Then build the mobile app again.

If the problem persists, create a case with [OutSystems Support](https://www.outsystems.com/support/portal/open-support-case?ErrorCode=OS-MCO-40015).
