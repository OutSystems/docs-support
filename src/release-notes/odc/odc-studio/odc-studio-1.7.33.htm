ODC Studio 1.7.33

Released on Nov 13, 2026

New in ODC Studio 1.7.33

  • Improved the spacing and the hover animation of the Mentor button in 1-Click Publish with message, and its drafting icon now matches the one in the Mentor chat. (RDEV-10468)
  • Reduced load times when opening libraries and the entry apps dropdown in the debugger. (RDEV-10767)
  • Native Semantic Search is now generally available in ODC, and it now includes Semantic Search over App Files. You can search the content of files stored in File attributes by meaning, without building a separate pipeline or keeping a copy of your documents in sync. Semantic Search over App Data and knowledge bases, previously in Beta, are now generally available too. (RDEV-10847)

Bug Fixing

  • Fixed an issue with resources above 256KB being lost when deleted by an external tool. (RDMST-4831)
  • Fixed an issue that slowed down 1-Click Publish when the publish required an automatic merge. (RDPIM-4467)
