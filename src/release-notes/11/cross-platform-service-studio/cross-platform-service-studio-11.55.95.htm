Cross-platform Service Studio 11.55.95

Released on Nov 02, 2026

New in Cross-platform Service Studio 11.55.95

  • You can now view and configure MCP read and write tool-call timeouts directly in the MCP Configuration dialog, preventing agent calls from timing out during heavy workloads. (R11DT-4171)

Bug Fixing

  • Fixed an issue where element change-tracking properties (such as Created By and Last Modified By) could be incorrectly overwritten when applying Model API changes via MCP. Now, Model API changes applied via MCP automatically attribute element authorship and timestamps to the signed-in developer. (R11DT-4256)
  • Fixed an issue that caused Service Studio to stop responding for several seconds while validating modules with many widgets that have width or margin values. (RDEV-10508)
  • Fixed an issue that caused Service Studio to stop responding for several seconds when refreshing the Toolbox in environments with many screen templates and sample blocks. (RDEV-10509)
  • Fixed an issue on macOS where the login in Service Studio never completed after developers signed in through the browser. This occurred on some machines after Service Studio was updated, and also affected other links that open Service Studio from the browser. (RDEV-10521)
  • Fixed an unexpected error when canceling Compare and Merge. (RDPIM-4439)
