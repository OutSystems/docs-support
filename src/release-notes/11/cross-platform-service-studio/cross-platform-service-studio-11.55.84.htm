Cross-platform Service Studio 11.55.84

This is a preliminary version of the document.

New in Cross-platform Service Studio 11.55.84

  • The Convert to Reactive command now automatically converts OutSystemsUIWeb and OutSystemsChartsWeb widgets, mapping them to their OutSystemsUI and OutSystemsCharts equivalents. Now supports widgets Accordion Item, Animate, Columns 2, Progress Bar, Separator, User Avatar from OutsystemsUIWeb, and widgets Area Chart, Bar Chart, Column Chart, Line Chart, Pie Chart from OutsystemsCharts. (R11DT-4025)
  • Improved Traditional To Reactive tool Server Action bundling. Server actions are now bundled with the nodes Assign, JSON Serialize/Deserialize and Excel conversions, into a single Server Action call, reducing unnecessary round-trips after conversion. (R11DT-4049)
  • Buttons and toolbar items now ignore repeated clicks made in quick succession, so a burst of clicks triggers its action only once. (RDEV-10059)

Bug Fixing

  • Fixed an issue where screen template storage could not be reconstructed when a malformed template was detected. (RDEV-10068)
  • Fixed an issue that caused an internal identifier to be inserted instead of the parameter name when dragging a parameter into the SQL statement of an Advanced Query. (RDPIM-4356)
  • Fixed an issue in UI Editor that caused the preview of some blocks to display 'Expression' instead of the configured property values, such as the column headers of a data grid. (RDPIM-4363)
