ODC Studio 1.7.34

Released on Nov 23, 2026

New in ODC Studio 1.7.34

  • It is now possible to download the files attached to messages in a Mentor chat, including chats resumed from the history. (RDEV-10294)
  • Improved the auto-arrange of logic flows that Mentor creates or edits, so that existing nodes keep their positions and only nodes placed too close to others are moved apart. (RDEV-10792)

Bug Fixing

  • Fixed an issue where the search bar didn’t open and showed an error message when a connection could not be established. (RDEV-10816)
  • Fixed an issue that caused the footer buttons of a plan in the Mentor chat to appear out of sight, making them look missing. This occurred when a response finished while the developer was scrolled to the bottom of the conversation. (RDEV-9848)
  • Fixed an issue that cut off the last character of the selected source name in the Join source dropdowns of Aggregates. (RDPIM-4492)
