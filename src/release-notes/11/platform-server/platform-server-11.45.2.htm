Platform Server 11.45.2

Released on Nov 19, 2026

Bug Fixing

  • Fixed a security vulnerability that allowed IT users to access information from solutions that they might not have had authorization. (RPM-7262) Application Lifecycle Service Center
  • Fixed a security issue that allowed low-privileged IT users to bypass publish permissions. (RPM-7332) Application Lifecycle Service Center
  • Fixed a security vulnerability in SAML authentication. (RPM-7336) Application Runtime Authentication and Authorization
  • Fixed a security vulnerability that allowed a low-privileged IT user to bypass process management permissions. (RPM-7339) Application Lifecycle Server.API
  • Fixed a security vulnerability that allowed low-privileged IT users to enable or disable environment-wide platform feature flags. (RPM-7340) Application Lifecycle Service Center
  • Fixed a security vulnerability that allowed low-privileged IT users to manipulate files uploaded via deprecated actions in RichWidgets. (RPM-7345) Application Runtime System Components
  • Fixed a security vulnerability that allowed unauthorised users to interfere with the EPA Taskbox component. (RPM-7350) Application Runtime
  • Fixed a security vulnerability that allowed low-privileged IT users to overwrite the environment-wide hostname configuration. (RPM-7351) Application Lifecycle Service Center
  • Fixed a security vulnerability that allowed low-privileged IT users to change another application’s mobile build configuration. (RPM-7353) Application Lifecycle Service Center
  • Fixed a security vulnerability that allowed low-privileged IT users to add or replace trusted Service Studio templates. (RPM-7355) Application Runtime System Components
  • Fixed a security vulnerability that allowed low-privileged IT users to change the environment-wide server extension recompilation policy. (RPM-7367) Application Runtime System Components
  • Fixed a security vulnerability in LDAP and AD authentication. (RPM-7375) Application Runtime
  • Fixed security vulnerabilities affecting OutSystems services. (RPM-7390) Application Lifecycle Service Center
  • Fixed a security issue that allowed a low-privileged IT User to change applications settings. (RPM-7432) Application Lifecycle Service Center
  • Fixed a security vulnerability in LDAP authentication. Customers using LDAPS should enforce the certificate validation via Factory Configuration. (RPM-7490) Application Runtime
