ODC Studio 1.7.31

Released on Nov 02, 2026

New in ODC Studio 1.7.31

  • Stopping a request in Mentor now restores the prompt and its attached files to the chat input. (RDEV-10128)
  • Mentor now rejects images larger than 3.75 MB and other files larger than 4.5 MB when they are attached to a prompt. (RDEV-10541)
  • You can now use Flex and Grid layouts in Containers, Placeholders, and Forms, and control how each child element grows, shrinks, or spans, directly from the Styles Editor. (RDEV-10784)
  • Mentor now keeps the library versions an app already uses when adding elements from that library, and only upgrades them when asked. (RDEV-9805)
  • You can now consume REST API methods that use the multipart/form-data request format, for example to upload files together with other form fields in a single request. Set the request format of the method in ODC Studio, and its body parameters are sent as separate parts. (RRCT-7906)

Bug Fixing

  • Fixed an issue that caused property input fields to unexpectedly expand when entering a value. (RDEV-10056)
  • Fixed an issue that caused ODC Studio to stop responding while editing, saving or publishing an app or library. (RDEV-10510)
  • Fixed an issue that cause the Mentor feedback dialog to show when not expected. (RDEV-9966)
  • Fixed an issue that caused the Mentor chat to scroll incorrectly when sending messages. (RDPIM-4244)
  • Fixed an issue where Mentor could stop opening from the button, menu or keyboard shortcut, even after restarting ODC Studio. (RDPIM-4393)
  • Fixed an issue that caused logic to be silently reintroduced after merge. (RPM-7308) Service Studio Merge operation
