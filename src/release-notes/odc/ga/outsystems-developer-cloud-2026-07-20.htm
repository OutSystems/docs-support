OutSystems Developer Cloud 2026-07-20

Released on Jul 20, 2026

New

  • When extending your ODC apps with O11 logic, you can now route REST API requests over a private channel, that you can allowlist in your O11 firewall or network access policies, instead of the public internet. Requires LifeTime 11.29 or later. For more information, refer to Logic interoperability. (RDUBR-365)
  • For interoperability purposes, an ODC tenant can now connect to more than one OutSystems 11 infrastructure. Requires LifeTime 11.29 or later. For more information, see Connect ODC to your O11 infrastructure. (RDUCH-300)
  • ODC apps can now consume O11 entities from multiple O11 infrastructures using Data Fabric. This enables you to consolidate into a single ODC tenant data from different O11 infrastructures that are segregated for compliance, governance, or business-unit isolation requirements. Requires LifeTime 11.29 or later. For more information, refer to Data interoperability. (RDUCH-314)
