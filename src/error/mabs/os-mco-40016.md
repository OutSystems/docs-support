# OS-MCO-40016

## Error message

`The app doesn't have a primary color. Define a primary color for the app in ODC Studio.`

## Cause

Your mobile app doesn't have a primary color defined. The primary color is mandatory to build a mobile app, because it's the default color for several of the app's visual elements.

ODC Studio sets a default primary color for every app you create with it. Apps created with other tools might not have one.

## Impact

The mobile compilation fails, causing the native mobile build to fail.

## Recommended action

Open the app in ODC Studio and set a primary color in the [app properties](https://success.outsystems.com/documentation/outsystems_developer_cloud/building_apps/libraries/edit_app_library_and_mobile_library_properties/#general-settings-general-settings). Then build the mobile app again.

If the problem persists, create a case with [OutSystems Support](https://www.outsystems.com/support/portal/open-support-case?ErrorCode=OS-MCO-40016).
