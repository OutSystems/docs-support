LifeTime Management Console 11.33.1

This is a preliminary version of the document.

New in LifeTime Management Console 11.33.1

  • On the Blocked Users screen in LT, reduced the space between the user and the action button as per suggested by Kilian Hekhuis (R11CT-3840) Application Lifecycle Service Center
  • Added the name and description fields to the VPN listing and creation screens as suggested by Nordin Ahdi. This will allow users to distinguish VPNs easier from one another. (R11CT-4152) Application Lifecycle LifeTime
  • The Platform Server version bundled with LifeTime was upgraded to 11.44.0 (R11CT-5137)

Bug Fixing

  • Fixed an issue in the authentication settings screen that caused an incorrect visual state to appear when adding or removing OIDC providers. Now, the screen correctly reflects the current state of the provider list. (R11CT-5131) Application Lifecycle LifeTime
