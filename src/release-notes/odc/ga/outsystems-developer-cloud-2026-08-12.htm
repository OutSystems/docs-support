OutSystems Developer Cloud 2026-08-12

Released on Aug 12, 2026

New

  • When inviting a user in the ODC Portal, you can now choose whether the user profile is created in the built-in identity provider or only in an external identity provider, depending on the providers assigned at the organization or stage level. Additionally, existing users without a built-in profile can be invited to the built-in provider, preserving their profile and assignments rather than requiring you to recreate the user. (RDPP-3378)
