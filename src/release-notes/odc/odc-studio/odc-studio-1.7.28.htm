ODC Studio 1.7.28

This is a preliminary version of the document.

New in ODC Studio 1.7.28

  • Now you can select all changes from one side at once when comparing and merging. (RDEV-9202)

Bug Fixing

  • Fixed an issue that allowed developers to drop multiple elements into an app even when some of them broke the dependency rules. This occurred when dragging several elements at once between apps. (RDEV-10314)
  • Fixed an issue that would cause an error when creating an app. (RDEV-10321)
  • Fixed an issue that caused Screens and Blocks containing Lists or Table Records to use excessive memory when opened, which could make ODC Studio stop responding or close unexpectedly. (RPM-7250)
