OutSystems Developer Cloud 2026-07-29

Released on Jul 29, 2026

New

  • The Code Quality public API's findings-trend endpoint now accepts ScoreRanges instead of Scores as its filter parameter. Update any integration that sends Scores. ScoreRanges also changed from an array to a string across assets-quality-metrics, findings-summary, findings-trend, common-findings-metrics, and quality-score-distribution: send it as one comma-separated value, for example 0-49,50-84,85-100, not as separate array items. (RDASS-4015)
