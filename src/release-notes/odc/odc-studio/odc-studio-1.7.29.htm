ODC Studio 1.7.29

Released on Oct 19, 2026

New in ODC Studio 1.7.29

  • It is now possible to access and resume previous Mentor conversations. (RDEV-10154)
  • You can now attach text files and images to a Mentor prompt. (RDEV-10438)

Bug Fixing

  • Improvements to some UI components. (RDEV-10141)
  • Fixed an issue causing shortcuts not to work correctly on text and code editors after opening the context menu. (RDEV-10240)
  • Fixed an issue that sometimes caused latency when opening an expression editor. (RDEV-10257)
  • Fixed an issue where the icon was missing on screens scaffolded from an entity when using the Phosphor Icon library in the theme. (RDEV-10348)
  • Fixed an issue that caused ODC Studio to crash when undoing or redoing a change with the app properties open. This occurred when the property selected in the Advanced Settings or Messages tab could no longer be found after the undo or redo. Now, the change is undone or redone as expected. (RDMDX-294)
  • Fixed an issue that caused an unexpected error when selecting text when performing a Compare and Merge. (RDPIM-4384)
  • Fixed an issue where typing in some properties did not open the dropdown with suggestions. (RDPIM-4434)
  • Improved the error experience in 1-click publish when the mobile app native build check fails. Now, the error information is shown as a warning because it does not compromise the publish operation. (RPM-7276)
