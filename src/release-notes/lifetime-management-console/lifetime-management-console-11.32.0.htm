LifeTime Management Console 11.32.0

Released on Sep 09, 2026

New in LifeTime Management Console 11.32.0

  • LifeTime now displays alerts when modules have unused producers. This helps you identify unnecessary references and keep your dependency graph clean. (R11CT-5117)

Bug Fixing

  • Fixed an issue that caused the LifeTime API v2 GET /users/ endpoint to not return the user key for users that had no infrastructure role associated. Now, the user key is correctly returned for all users regardless of whether they have an infrastructure role. (R11CT-5094) Application Lifecycle LifeTime
