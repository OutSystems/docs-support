OutSystems Developer Cloud 2026-08-10

Released on Aug 10, 2026

New

  • GET /code-quality/v1/analysis-status now takes an optional portfolioKey parameter. Pass it to scope the analysis status to one portfolio instead of the whole tenant. Leave it out and the response aggregates every portfolio's latest analysis run into one result. If no analysis has run yet for the scope you asked for, the endpoint now returns a 200 with an empty result instead of a 404. The isLatest filter on GET /code-quality/v1/findings follows the same rule: add portfolioKey for one portfolio's latest findings, or leave it off for the latest findings across every portfolio. (RDASS-3893)

Bug Fixing

  • Fix an issue that prevented the O11 infrastructure name from being displayed for O11 Self-Managed connections. (RPM-7045)
