OutSystems Developer Cloud 2026-10-19

Released on Oct 19, 2026

New

  • OutSystems MCP: Added two Beta skills to the OutSystems plugin: spec-driven-build, to build an app from a written spec, and custom-code, to create, test, and deploy C# External Logic libraries. (RDCAG-154)
  • It is now possible to reopen an earlier conversation with Mentor and continue where you left off. (RDCAG-47)
  • You can now attach text files and images to a Mentor prompt to give Mentor in ODC Studio more context. (RDCAG-83)

Bug Fixing

  • OutSystems MCP: Fixed an issue that caused publishing to fail when you created or changed an app through the OutSystems MCP, including apps created without a template. (RDMOR-4651)
  • OutSystems MCP: Fixed an issue that caused Mentor to run out of memory when it loaded large apps with many referenced Blocks. (RDMOR-4688)
