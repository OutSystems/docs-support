Released on Nov 03, 2026

Bug Fixing

  • Fixed an issue where the details of some active workflow instances couldn't be opened in the Workflows console, showing error OS-WFC-60001. This happened when a parallel branch hadn't yet reached the step where the branches join, for example while a failed activity was being retried. Affected instances now open normally, with no action needed. (RPM-7414)
