OutSystems Developer Cloud 2026-08-15

Released on Aug 15, 2026

New

  • The Code Quality pattern "Server call in the logic of a screen accessible to everyone" splits into two patterns: "Server call exposed on a screen accessible to everyone" and "Database operation in the client-side logic of a screen".

    We split it because it combined two separate findings, and one poses an elevated risk relative to the other.

    Server call exposed on a screen accessible to everyone moves from High to Critical, because it fires on screens with the Anonymous role: the server calls those screens make turn into endpoints anyone can call over the internet without logging in. (RDASS-4063)
