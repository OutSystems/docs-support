Cross-platform Service Studio 11.55.88

This is a preliminary version of the document.

New in Cross-platform Service Studio 11.55.88

  • Updated the Convert to Reactive command to reduce the number of server requests by grouping consecutive server action calls, and the logic between them, into one request whenever possible. (R11DT-4063)
  • Added support for migration of RichWidgets widget Modal, and associated action ToggleModal, to the Convert to Reactive command. (R11DT-4151)

Bug Fixing

  • Fixed an issue in the Traditional to Reactive command where screen input parameter sharing a name with a site property would result in an error. (R11DT-4155)
  • Fixed an issue that caused Extract to Action to fail with error “an item with the same key has already been added“. This occurred when extracted nodes were referenced from outside the selection. (R11DT-4201)
  • Fixed Finding Usages window showing an arrow for results that were not expandable. (RDEV-10208)
