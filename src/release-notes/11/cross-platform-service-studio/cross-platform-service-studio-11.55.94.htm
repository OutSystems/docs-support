Cross-platform Service Studio 11.55.94

This is a preliminary version of the document.

New in Cross-platform Service Studio 11.55.94

  • Service Studio now brings its window to the foreground, restoring it if minimized, when an MCP agent requests a connection or an interactive merge conflict needs resolving, so the popup is no longer missed. (R11DT-4105)
  • Fixed an issue that caused the Studio to freeze and use excessive memory while searching. (RDEV-10344)

Bug Fixing

  • Fixed an error during Traditional-to-Reactive conversion involving disabled Aggregates referencing input parameters or server action outputs. (R11DT-4377)
  • Fixed an issue where setting the MCP Server port to a value between 1024 and 9999 was rejected and fell back to the default port. Now you can configure the MCP Server port using any port in the registered range from 1024 to 49151. (R11DT-4394)
  • Improved the edit data experience: the context menus now show disabled items correctly and group options with separators, the confirmation message shown when you apply edited data is now centered, and secondary buttons now use the correct background color in the light theme. (RDEV-10141)
  • Fixed an issue that caused the Check for Updates option in the Help menu to download the Intel (x64) version of Service Studio on Mac computers with Apple silicon. (RDPIM-4443)
