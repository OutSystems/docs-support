OutSystems Developer Cloud 2026-11-15

Released on Nov 15, 2026

New

  • Mentor now checks the Mentor permission on the server, so developers whose role doesn't include it can't use Mentor from any client. (RDCAG-380)
  • OutSystems MCP: You can now call the OutSystems MCP tools from ODC agentic apps, using an API client with a System to system (OAuth) connection, so agents that run in ODC can read your tenant and use Mentor. (RDEV-10821)

Bug Fixing

  • Fixed an issue where values assigned through List.Current on the output of an Aggregate or SQL node were reverted to the database values. This occurred in server-side logic when the list was first read, by iterating or indexing it, after the assignment. Now, the assigned values are kept. (RPM-7470)
