OutSystems Developer Cloud 2026-10-31

Released on Oct 31, 2026

New

  • Monthly Security Update (October 2026): Updated application container base image, including security fixes. Check the Microsoft .NET 10.0.13 and 10.0.14 releases for more details: https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.13/10.0.13.md and https://github.com/dotnet/core/blob/main/release-notes/10.0/10.0.14/10.0.14.md (RRCT-7943)

Bug Fixing

  • Fixed an issue where, in apps using external IdPs, users could get stuck on the login redirect page if the login state was lost; the app now redirects to the home screen, if no other redirect occurred while handling the exception. (RPM-7283)
  • Fixed an issue where, after a Back navigation with a transition animation, later screen navigations played that Back transition in the wrong direction until the app was reloaded. (RPM-7382)
