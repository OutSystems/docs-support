Cross-platform Service Studio 11.55.98

Released on Nov 23, 2026

New in Cross-platform Service Studio 11.55.98

  • The Service Studio MCP server now lets AI agents find the applications and modules of the environment Service Studio is connected to, including modules that aren't open, with the new searchApps tool. The listApps tool, which used to list the open modules, is now named listOpenModules. (R11DT-4381)
  • Convert to Reactive now maps the RichWidgets date and address functions used by server actions to OutSystemsReactiveMigration, and fixes aggregate pagination, default sort, LineCount replacement and CheckRegisteredRole conversion issues. (R11DT-4475)
  • The Traditional to Reactive command now converts expressions correctly when an extracted node's name appears more than once, no longer repeating its output prefix. (R11DT-4482)
  • The Traditional to Reactive command now provides the functions that converted logic calls: RichWidgets functions, CheckRegisteredRole and GetApplicationName. Functions that OutSystemsReactiveMigration already offers as client actions are bound to them instead of being mocked. (R11DT-4483)
  • The Traditional to Reactive command now fixes two widget and data issues: references to a replaced static entity's identifier type follow the OutSystemsReactiveMigration version, and a ProgressBar without a Percentage converts with Progress set to 0. (R11DT-4484)

Bug Fixing

  • Fixed an issue where the listApps tool of the Service Studio MCP Server returned a different key for the same module every time it was opened. (R11DT-4279)
  • Fixed an issue where Convert to Reactive crashed when converting Processes that contain SendEmail nodes. Each SendEmail node is now replaced with an empty Automatic Activity node, along with a reminder to edit it manually later. (R11DT-4486)
  • Fixed an issue that cut off the last character of the selected source name in the Join source dropdowns of Aggregates. (RDPIM-4492)
  • Fixed an issue that prevented opening a module when the username or password started with a hyphen. (RPM-2835) Service Studio Command line
  • Restricted the usage data collected by the O11 MCP Server to basic tool usage and performance metrics. (RPM-7415) Service Studio
  • Fixed an issue where Reactive modules edited through the Service Studio MCP could lose the Feedback Message icons after publishing. (RPM-7484) Service Studio AI-Assisted Development
