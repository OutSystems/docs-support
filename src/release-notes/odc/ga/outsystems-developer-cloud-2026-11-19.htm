OutSystems Developer Cloud 2026-11-19

Released on Nov 19, 2026

New

  • The history of a Code Quality finding now shows when the system closes it because an analysis no longer reports it, and when a closed finding comes back. A finding the system reopens appears as Open, not Reopen, and each history entry records whether a person or the system made the change. Only the system can close a finding, so setting a finding to Closed through the findings status API now returns a 400 error (OS-AIMS-40019). (RDAN-3841)
