OutSystems Developer Cloud 2026-07-27

Released on Jul 27, 2026

New

  • The Portfolios/v1 public API is now deprecated but will remain functional until January 8, 2027, when it will be sunset. Please check the guide for transitioning to Portfolios v2. (RDMAST-2881)
  • Workflow Editor: Merge Revisions
    • You can now automatically merge two workflow revisions in the Workflow Editor. When a newer revision is published while you are editing, select "Merge both versions" in the comparison view to intelligently combine changes from both versions.
    • The system performs element-level conflict detection, automatically merging modifications, additions, and deletions only when both sides agree. Elements involved in conflicting changes are highlighted using color coding, allowing you to review them before publishing the merged result.
    • You can access the automatic merge feature from two scenarios:
      • When publishing - If a newer revision was published while you were editing, merge both versions before deciding to publish your changes.
      • Opening a workflow - If a colleague published a new revision while you had unsaved changes, merge the versions to combine your work with theirs before continuing to edit.
    (RDODCT-4483)

Bug Fixing

  • Fixed an issue that prevented the correct filtering by the OutSystems11 provider on the Connections screen. (RPM-7046)
  • Fixed an issue that prevented the creation of an O11 Cloud connection, since it was impossible to select an O11 environment to which to establish the connection. (RPM-7056)
