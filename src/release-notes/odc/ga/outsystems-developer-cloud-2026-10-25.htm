OutSystems Developer Cloud 2026-10-25

Released on Oct 25, 2026

New

  • Improved the Thinking section of Mentor, which now shows a short heading for what Mentor is working on, followed by its reasoning, instead of rotating status messages. (RDCAG-95)
  • OutSystems MCP: It is now possible to name the app in your prompt when you work with Mentor through the OutSystems MCP, and to work on more than one app in the same session. The mentor_load_asset and mentor_create_asset tools were removed, so update the OutSystems plugin or skill to version 1.10.0. (RDMOR-4571)

Bug Fixing

  • Fixed an issue that caused a Mentor conversation to have no title when it started with an attachment and no prompt text. (RDCAG-144)
  • Fixed an issue that caused Mentor generated publish messages in ODC Studio to ignore the app's language, describe large changes poorly, or get cut off when they were longer than 500 characters. (RDCAG-74)
  • Fixed an issue that caused SQL queries generated by Mentor in ODC Studio to fail when Mentor used True instead of 1 for Boolean values. (RDCAG-85)
  • OutSystems MCP: Fixed an issue that caused requests meant for OutSystems 11 to reach your ODC tenant when both the ODC MCP server and the Service Studio MCP server were connected. (RDEV-10482)
  • Fixed an issue where icons could be missing in applications after a security patch when the application's theme did not define an icon library. (RPM-7282)
