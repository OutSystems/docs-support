ODC Studio 1.7.32

Released on Nov 08, 2026

New in ODC Studio 1.7.32

  • Improved Studio performance and responsiveness when editing large UI flows. (RDEV-10535)
  • It is now possible to attach files to the Mentor chat by dragging them from the file system and dropping them onto the chat. (RDEV-9993)
  • Allow SVG elements and newer HTML tags in the Advanced HTML widget (RDMST-5372)
  • Fixed an issue that caused 1-Click Publish to continue after cancelling the "Refreshing elements" step of an automatic merge. (RDPIM-4490)

Bug Fixing

  • Fixed an issue that caused an unexpected error when trying a library. (RDEV-10450)
  • Fixed an issue that occasionally caused the IDE to stop responding when selecting widgets in a screen or block. (RDEV-10506)
  • Fixed an issue that occasionally caused the IDE to stop responding when closing the Expression Editor or the SQL, JavaScript or CSS editors. (RDEV-10507)
  • Fixed an issue that caused the content of complex screens to disappear from the canvas when opening them. (RDEV-10547)
  • Fixed an issue that prevented dropping files from the file system, for example to open OML files, import entities from Excel, or add images and resources. (RDEV-10787)
  • Fixed issue where characters typed immediately after adding a new element were lost until the name editor opened (RDEV-10794)
  • Fixed an issue where the color picker closed automatically when clicked. (RDEV-9911)
  • Fixed an unexpected error when canceling Compare and Merge. (RDPIM-4439)
  • Fixed issues that unexpectedly signed developers out of open ODC Studio windows and required logging in again through the browser. (RPM-7154) Service Studio
  • Fixed an issue that prevented consuming a REST API from an OpenAPI specification, showing the message “We couldn’t process the Swagger file”. This occurred when the specification used the same nullable enumeration, listing null as one of its values, in more than one place. (RPM-7281) Service Studio Logic
  • Updated the Node.js runtime bundled with Studio to version 24.22.1. (RPM-7387) Service Studio
