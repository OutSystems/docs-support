LifeTime Management Console 11.31.0

Released on Aug 26, 2026

New in LifeTime Management Console 11.31.0

  • LifeTime now displays alerts when modules have unused producers. This helps to identify unnecessary references and keep your dependency graph clean. (R11CT-5111)
  • It is now possible to monitor the performance of Reactive Web and Mobile applications in LifeTime Analytics, alongside Traditional Web applications. Review the APDEX score of an application, drill down into screens, web blocks and actions to find slow queries, extensions and integrations, and use Open in Code Quality to inspect the patterns behind the problem. Available as a Beta. For more information, including how to enable it, see Performance Analytics for Reactive and Mobile apps. (R11CT-5112)

Bug Fixing

  • Fixed an issue that caused the list of additional secure endpoints to overflow and hide the 'Update additional secure endpoints' button. This occurred when the list had a large number of records. (RPM-6729) Application Lifecycle LifeTime
